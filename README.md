# Dynamic queue in c

A dynamic queue Implementation in c.(Downloadable header files).

I am just learning out low-level programming, so please don't yell at me while reading the code :D

# Usage

You can use it as a library. Just `git clone https://github.com/mrgamernavshorts/queue-c-dynamic`, and import the following:

> [!CAUTION]
> There are no include guards, don't include anything twice.


```c
#include "include/queue.h"
```

You will just need to link the `queue.c` file when compiling. for eg ->
```bash
gcc main.c include/queue.c -o main
```

You can view the documentation in the `include/queue.h` file.

If you find a bug, feel free to make a issue :D
